# Cruise Adventure - Voice Lines v0.4 (To the car)

New lines for the trunk puzzle. As before, the helper sibling says them, so **Jack-Jack records them for Becca's game** and **Becca records them for Jack-Jack's game**. One file per line, named roughly after what's said, works fine.

| Line id | Words | When it plays |
| --- | --- | --- |
| `load-car` | "Let's put all the bags in the car!" | The puzzle starts |
| `turn-it` | "Tap it to turn it!" | The child drags a bag that would fit if it were turned |
| `try-another-spot` | "Hmm... try another spot!" | A bag slides back out |
| `it-fits` | "It fits!" | A bag snaps into place (rotates with the existing cheers: "You found it!", "Yay! Good job!", "That's the one!") |
| `close-trunk` | "Everything's in! Close the trunk!" | The trunk is full |
| `lets-go` | "Airport, here we come!" | The hatch shuts |

Six lines for each kid. The current cheers already recorded for packing are reused.
