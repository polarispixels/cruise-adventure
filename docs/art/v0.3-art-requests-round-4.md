# Cruise Adventure - Art Requests Round 4: Buttons

Please make three round buttons for the end-of-level screen in the game. The game already has stand-ins, so this isn't blocking anything. Yours will replace them as-is.

## The three buttons

| File name | What it means | Color | Picture on it |
| --- | --- | --- | --- |
| `button-home.png` | Go back to the title screen | Blue | A simple house: a roof, a chimney and a door |
| `button-replay.png` | Play this row again | Orange | One curved arrow going around in a circle, with a clear arrowhead (a "do it again" arrow) |
| `button-continue.png` | Keep going to the next part | Green | A big, fat arrow pointing right |

## Style
- Same cartoon style as the characters and props: thick dark outlines, flat bright colors, a little shine at the top so they look tappable.
- Make the picture white or very light, big and chunky, filling about 60% of the circle. A 4-year-old has to tell the three apart from across the room without reading.
- No words or letters on the buttons.

## Format
- PNG, 512 x 512, transparent background. Only the circle; nothing outside it.
- All three the same size, with the same outline thickness.
- Save them in `Game Assets/UI/` with the file names above.
