## Decisions and defaults (the lead's calls)

- **D1.** `v0.5.0` is not tagged (tags today: v0.1.0, v0.3.0), so T4 (runtime tinting) is skipped per spec F7 and listed in the final report.
- **D2.** T1 is approved by the build spec: all 12 clips convert to 854x480. The `optimize` branch work (T5, T2, T6, one test clip) is folded into `v1.0`.
- **D3.** Phase 0 runs as three Framework agents in parallel by file area (A: registry/player/map/save; B: engines; C: placeholders and size), after a short contract commit, then A integrates and runs the dummy chapter. One agent for all of F1-F7 would outgrow its context.
- **D4.** Engine contract: the segment player sets `Game.segment` (a Dictionary, already merged for the current kid: common fields with the `jack` or `becca` block laid over them) before changing scene; a segment scene calls `Game.segment_done()` when finished. Engines live in `scenes/engines/<name>.tscn` + `scripts/engines/<name>.gd`. Voice is `Voice.say(line_id, Game.sibling(), wait)`, sounds `Sfx.play(name)`, glows `Glows.show_rects()`.
- **D5.** Existing chapter scenes (room, trunk, checkin, security, maze) are registered in `data/chapters.json` and driven by the segment player, but their code is not rewritten into the engines. The engines extract the models (`trunk_model`, `maze_model`) and the shared behaviors; chapters 1-8 must play exactly as before, and a rewrite risks that for no player-visible gain.
- **D6.** Stills live at `assets/stills/<clip-name>.png` and match `assets/video/<clip-name>.ogv` by name. Placeholder stills are generated at 854x480.
- **D7.** Worktrees for parallel agents live in `/home/rgris/code/cruise-adventure-wt/<branch>/`.

- **D8.** Ryan amended the build spec on Nov 1 (progress tracking at every milestone). The Briefs and docs agent owns it on branch `briefs`, merged into `v1.0` at each milestone; the lead does not edit the Status block.
- **D9.** The six chapter specs were written while Phase 0 ran (builders keep their context for the build step), since spec writing depends only on the build spec and the template.
- **D10.** Clips at 854x480 come out at 1.50 to 1.53 MB, a hair over the 1.5 MB guideline; accepted under the 90% rule, bitrate unchanged.
- **D11.** Two generators made the map stop icons; the placeholder pipeline's (manifest-registered, `data/chapters/map-art.json`) win and `tools/make_map_stops.py` goes.
- **D12.** Builders for chapters 9, 10, 11 and 13 start on the merged framework before the dummy-chapter check finishes, to protect the Nov 3 date; 12 and 14 follow because they reuse 13's and 11's sprites. Framework B's call that Match picks by tap (not drag) is accepted: simpler for a 4-year-old.
