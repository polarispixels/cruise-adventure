# Chapter 8 (The Airport) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole airport chapter, playable on the tablet: the car's Continue leads to the airport. The kid's airport clip plays, then three games: Goodbye suitcases (tag the bags, belt), Through security (trays, scanner, arch, collect) and Find our gate (a fresh maze every play). Then the jet-bridge clip and the finish buttons.

**Architecture:**
- Three scenes (`checkin.tscn`, `security.tscn`, `maze.tscn`) chained by `Game`, each drawn on a 1672x941 background stage like the room.
- Rules live in pure, tested models. `MazeModel` generates, solves and measures mazes. The check-in and security scenes keep their small state in the scene.
- Per-kid differences are `KidProfile` data.
- Sounds and the airport music bed are synthesized placeholders, like the theme.

**Tech Stack:** Godot 4.7.2 GDScript, the headless test runner, the Python asset tools (numpy synth, PIL).

### Task 2: MazeModel

`scripts/maze_model.gd`, `class_name MazeModel extends RefCounted`.

- `static func generate(size: Vector2i, braid: float, loops: int, max_turns: int, gates: int, rng: RandomNumberGenerator) -> MazeModel`
  - It builds a randomized depth-first maze, removes `braid` of the dead ends, and opens `loops` extra walls.
  - The start is a cell in column 0. Gates are openings in the right boundary on distinct rows, spread out, and one is chosen `correct`.
  - If the shortest path to the correct gate has more turns than `max_turns`, it regenerates internally (up to 200 tries with the same rng), so it always returns a valid maze.
- `var size`, `var start: Vector2i`, `var gates: Array[Vector2i]` (the right-column cell each gate opens from), `var correct: int`
- `func open(a: Vector2i, b: Vector2i) -> bool`: neighbors with no wall between them.
- `func path(from: Vector2i, to: Vector2i) -> Array[Vector2i]`: BFS.
- `func turns(path) -> int`, `func dead_ends() -> int`
- Tests:
  - `test_every_cell_reachable`
  - `test_gates_on_the_right_edge_distinct_rows`
  - `test_start_in_the_left_column`
  - `test_becca_path_has_at_most_four_turns`
  - `test_jack_has_dead_ends_and_loops` (dead ends >= 3, loops: edges > cells - 1)
  - `test_many_seeds_meet_the_rules` (200 seeds per kid)
  - `test_same_seed_same_maze`

### Task 4: The maze scene

- **Layout:**
  - Background: `airport-terminal-floor.png`.
  - Walls: rounded Line2D strokes, an outline under the fill.
  - Gates sit outside the right edge, facing in. Jack-Jack's boarding pass (the correct color) is in the bottom-left corner.
  - Up to 4 decor pieces go in dead-end cells, never on the shortest path.
  - The player's face token starts at `start`, and the sibling's token trails behind.
- **Token movement:**
  - The token lives on the corridor graph, on a segment between two open neighbors or a cell and its gate, at a position along it.
  - A drag pulls it toward the finger along the graph: it projects onto the current segment, and at a node it switches to the open segment pointing most toward the finger, repeated until settled.
  - It moves at most 0.5 cell per step and runs as many steps as it needs.
  - A press counts only on the token (radius 0.6 cell). Lifting the finger leaves the token where it is.
- **Gates:**
  - Reaching a gate node checks it: the correct gate → `found-gate`, both kids cheer, then the payoff clip, `mark_airport_done`, Finish (home, replay → `play_airport`, continue → map).
  - A wrong gate → the `hmm` pose and `not-this-one`; the token stays where it is.
- **Hints:** after `maze_hint_delay` with no new closest-to-goal node, the sibling's token bounces and the helper says `this-way`. Becca also gets footprints on the next 3 cells of the path from the token's node.
- **Voice:** `find-gate` at the start, then `match-airplane` for Jack-Jack.
- **Payoff:** the clip ignores skip taps for 0.75 s, as in the trunk.
- Tests:
  - `test_drag_moves_along_a_corridor`
  - `test_token_never_crosses_a_wall` (random drags, checked against the model)
  - `test_lifting_leaves_the_token`
  - `test_reaching_the_right_gate_finishes`
  - `test_wrong_gate_says_not_this_one` (jack)
  - `test_becca_footprints_hint`
  - `test_layout_fits_16_9_and_16_10`
  - `test_finish_buttons`

  - Items wait on the floor, at the security item sprites from the kid's props and the car bags.

- **Trays:**
  - Drag an item into a tray. With `tablet_own_tray`, a tablet in a shared tray (or an item dropped onto the tablet's tray) hops to an empty tray → `tablet-tray`.

- **Collecting:** drag each item from the trays to the backpack (now on the floor by the kid). The buddy goes to the kid → hug + `hug-buddy`. When everything is collected, `done()`.
- Tests: `test_item_goes_in_a_tray`, `test_tablet_hops_to_its_own_tray` (jack, both orders), `test_becca_tablet_shares_a_tray`, `test_tray_goes_through_the_scanner`, `test_buddy_comes_back_line`, `test_arch_after_everything_is_through`, `test_collecting_everything_goes_to_the_maze`.
